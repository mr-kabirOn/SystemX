SystemX: device info and phone diagnostics, rebuilt for the Play Store

This plan turns the current one-screen prototype into a full Android app. It shows live device stats, every spec the phone exposes, and a guided hardware checkup with a shareable report. Everything runs on the phone. There is no account, no server and no tracking.

Product principles

Five rules every feature has to follow

1 · Honest numbers

Every value comes from the system. Estimates are labelled as estimates, and anything Android blocks says "Not available on this device" instead of showing a guess.

2 · Private by design

No account, no analytics SDK and no server. Data never leaves the phone unless the user shares a report. The Play listing can then state "No data collected".

3 · Works with zero permissions

The core app needs no permissions. Each extra one is requested only when the user opens the feature that needs it, with a one-line reason.

4 · No fake boosters

No "RAM cleaner", "CPU cooler" or "battery doctor" buttons. They don't work on modern Android and they break Play's deceptive-behavior policy. SystemX gives real, actionable tips instead.

5 · Glanceable first, deep second

Each screen leads with one clear status, such as a health score or a battery state, and opens up to full detail for enthusiasts.

Design system

An instrument panel in your pocket

The visual idea comes from lab instruments and cockpit gauges. Surfaces are dark and calm, readouts use a monospace face so digits don't jump while they update, and each hardware area has its own color, used the same way everywhere. Dark is the default theme. A light theme, a pure-black AMOLED theme and Material You wallpaper colors are all options in Settings.

Notifications & background work

Live, useful and always under the user's control

Live status (optional)

  • Ongoing notification with battery %, temperature, charging watts, network speed and RAM
  • The status bar icon can show live network speed or battery temperature as a number
  • Runs as a foreground service that the user turns on. It is off by default and has a Stop button.

Alerts (each can be turned off, with its own threshold)

  • Charge limit reached, battery low, battery hot
  • Charging finished, with a session summary
  • Storage almost full
  • Weekly health summary and a monthly checkup reminder

How it stays battery-friendly

  • Live updates run only while the app is open or live status is on
  • History uses WorkManager every 15 minutes, plus charger plug and unplug events
  • Separate notification channels, so users can mute any type in Android settings

Permission timing

  • The notification permission (Android 13+) is asked when the user turns on an alert or live status, never at launch
  • If the user denies it, the toggle explains why and links to settings
Security, privacy & Play policy

Built to pass review the first time

Data & privacy

  • No account, backend, analytics or ads SDK, so Data safety can say "No data collected or shared"
  • Crash and ANR reports come from Play Console's Android vitals, so no extra SDK is needed
  • History stays in a private app database protected by Android's sandbox and file encryption
  • "Clear all history" button. Uninstalling removes everything.

App hardening

  • R8 code shrinking and obfuscation, plus resource shrinking, in release builds
  • No logs in release builds
  • Only the launcher, widget and tile are exported. Everything else is private.
  • Cleartext network traffic blocked. Backup rules limited to settings.
  • Dependencies only from Google Maven and Maven Central, with license notices in the app

Permissions we will never request

  • READ_PHONE_NUMBERS, QUERY_ALL_PACKAGES, background location, storage write, SMS and call log
  • These are restricted or sensitive on Play and none of our features need them

Play policy checklist

  • Target API 36, 16 KB page-size ready (no native code)
  • Foreground service type specialUse declared, with a short demo video
  • Store listing makes no exaggerated claims ("speeds up", "cleans")
  • Privacy policy URL, content rating, target audience 13+, ads declaration
